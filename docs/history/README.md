lived in `plx/agent-hook-kit`. They moved with the formatter/linter product in
August 2026 so its rationale remains beside the code it describes.

Historical command names, crate paths, `.agent-hook-kit` directories, and
planning status are intentionally preserved. For current installation and
configuration, use the repository [README](../../README.md) and the unified
`velvet-glove` CLI.
